# Общий инструмент обновления

```bash
./run.sh --date 2026-09-18
./run.sh --date 2026-09-18 --sources hpo --out /tmp/hpo-dataset
```

Подробная инструкция, схема каталогов и правила объединения: [data/README.md](../../README.md).

Без `--out` обновляется `data/datasets`. Результат — только обычные `results.csv` и `results.json`; версии и служебные файлы не сохраняются. Сначала вызывается соседний `download_and_convert/run.sh`, затем `append_data_tool/append_csv.py` и потоковое объединение JSON.

Параметры загрузчика передаются дальше. `--strict` запрещает обновлять датасет неполной выгрузкой; `--plan-only` показывает план без загрузки. Повтор той же даты заменяет соответствующие строки, не создавая дублей. Используйте тот же набор `--sources`, чтобы сохранить состав факторов в обновляемых строках.

Временные файлы удаляются автоматически. Оба результата читайте после успешного завершения команды: каждый файл заменяется атомарно, а вся пара — последовательно. При обычной ошибке публикации выполняется откат.

Проверки:

```bash
python3 -B -m unittest discover -s tests -v
```
