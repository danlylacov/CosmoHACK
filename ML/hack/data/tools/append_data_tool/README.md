# Добавление свежего CSV в базу

Для загрузки с добавлением в общий датасет используйте [единый инструмент](../../README.md). Ниже — отдельный запуск этого компонента.

Python 3.9+, без внешних зависимостей. На входе два CSV: сначала накопленная
база или старая выгрузка, затем свежая выгрузка.

Из `/Users/ivacshsergey/hack/data/tools`:

```bash
# Обновить базу на месте.
python3 append_data_tool/append_csv.py ../datasets/results.csv fresh_series.csv

# Или сохранить объединение в отдельный файл.
python3 append_data_tool/append_csv.py old.csv new.csv merged.csv
```

Инструмент объединяет строки по `time_utc` и сортирует результат по времени.
На каждую временную отметку остаётся одна строка. При совпадении времени
**целиком используется строка второго, свежего файла**, включая пустые значения:
так обновляются среднее, min/max/last/count ещё не завершённого 30-минутного окна.
История за пределами свежей выгрузки сохраняется.

Например, база содержит окна `12:00`, `12:30`, а свежая выгрузка — `12:30`,
`13:00`. Результат содержит `12:00` из базы и `12:30`, `13:00` из свежей выгрузки.
Статистики повторно не усредняются и счётчики не суммируются.

- Если внутри одного файла есть одинаковые временные отметки, используется
  последняя строка файла с этой отметкой.
- Повторный запуск с той же выгрузкой не меняет результат и не создаёт дублей.
- Время нормализуется в UTC: `Z` и эквивалентные смещения обозначают один ключ.
  Время без часового пояса считается UTC.
- Сохраняется объединение колонок обоих CSV: сначала колонки первого файла,
  затем новые колонки второго. Недостающие в выбранной строке поля остаются
  пустыми. Числа и текстовые значения переносятся без пересчёта и округления.
- Оба входных файла должны существовать и иметь заголовок. CSV только с
  заголовком подходит для первоначально пустой базы.
- Результат записывается через временный файл с атомарной заменой. Ошибка
  чтения или записи не заменяет существующую базу.

Запускайте объединение после завершения формирования свежего CSV. Разница
между выгрузками может быть 10 минут или другой: инструмент использует время
строк, а не время создания файлов. Порядок аргументов задаёт приоритет.

Для CSV прогнозов можно выбрать другой ключ:

```bash
python3 append_data_tool/append_csv.py old_forecasts.csv new_forecasts.csv --time-column issued_at_utc
```

Проверки:

```bash
python3 -m unittest discover -s append_data_tool -v
```
