# Шкалы NOAA в прогнозе ВКД

Наши данные позволяют оценивать три независимые [шкалы NOAA](https://www.spaceweather.gov/noaa-scales-explanation): **G** — геомагнитные бури, **S** — солнечные радиационные бури, **R** — радионарушения.

| Шкала | Колонка нашего CSV | Соответствие уровням 1 → 5 |
|---|---|---|
| G | `geomagnetic_kp` | Kp: 5; 6; 7; 8, включая 9−; 9. Для дробного Kp нужна явная таблица соответствия выбранного продукта, без простого округления |
| S | `proton_flux_above_10_mev_max` | Нижние пороги: 10; 100; 1 000; 10 000; 100 000 pfu |
| R | `solar_xray_flux_long_max` | Нижние пороги: 10⁻⁵; 5×10⁻⁵; 10⁻⁴; 10⁻³; 2×10⁻³ Вт/м² — классы M1, M5, X1, X10, X20 |

Для S используется поток протонов ≥10 МэВ, `1 pfu = 1 протон/(см²·с·ср)`. Для R — рентгеновский канал 0,1–0,8 нм.

## Получасовые окна

- S и R рассчитываем по максимумам внутри окна: среднее может скрыть пик.
- G сохраняет трёхчасовую природу Kp: значение повторяется в шести получасовых окнах. Hp30 не подставляется вместо Kp.
- При достаточных данных ниже первого уровня записываем `0` — наше обозначение отсутствия превышения. При недостаточных данных — `null`; наблюдаемый пик неполного окна сохраняем отдельно как нижнюю оценку максимума.
- Текущий CSV объединяет источники и не сохраняет приборные флаги. Результат обозначаем как **расчётную оценку по порогам NOAA**.

Официальные предупреждения требуют дополнительных правил. Например, протонный Alert подтверждается тремя последовательными пятиминутными превышениями; получасовой максимум не позволяет проверить их последовательность. Для воспроизведения нужны исходные измерения выбранного NOAA спутника и контроль качества. [Описание процедуры NOAA](https://agupubs.onlinelibrary.wiley.com/doi/abs/10.1029/2022SW003346).

## Выход модели

В каждое из **64 окон на 32 часа** добавляем `g_level`, `s_level`, `r_level`: переводим прогнозируемый Kp и максимумы потоков в категории. При наличии калиброванного вероятностного прогноза добавляем вероятности превышения уровней, например `p_s_ge_1`; номер уровня сам по себе вероятности не задаёт.

Шкалы используются для объяснения `eva_allowed`. S наиболее непосредственно связан с солнечной радиационной обстановкой; G и R описывают другие воздействия. Уровни не складываются в общий балл и сами по себе не определяют допуск к ВКД: необходима отдельная политика с учётом условий на МКС.
